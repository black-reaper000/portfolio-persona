# Persona Style Portfolio

A personal portfolio website inspired by the visual style of Persona 3 Reload.

I made this project to practice web development, UI design, animations,
transitions, and interactive layouts.

🎮 **Live Demo**: [https://black-reaper000.github.io/portfolio-persona/](https://black-reaper000.github.io/portfolio-persona/)

## About

The website includes:

-   About section
-   Projects section
-   Skills section
-   Contact section
-   Project previews
-   Animated navigation
-   Video background
-   Page transitions
-   Custom SVG project diagrams

## Tech Used

-   HTML
-   CSS
-   JavaScript
-   SVG

No frameworks were used.

## Projects

### Niple

A project focused on audio streaming between devices.

### Aternos AFK Bot

A Minecraft bot project for keeping a server active through automated
actions.

### SST Opportunities

A platform concept for helping students discover opportunities and
activities.

### Campus Launchpad

A platform concept for students to discover projects, teams and
opportunities.

## How to Run

Clone the repository and open `index.html` in your browser.

You can also use VS Code with Live Server.

## Project Structure

``` text
Portfolio/
├── index.html
├── style.css
├── script.js
├── video.mp4
├── images/
└── README.md
```

## Customizing

Most of the content can be changed in `index.html`.

Project interactions are handled in `script.js`.

The design, animations and layout are mainly in `style.css`.
